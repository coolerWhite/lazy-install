# post-install

Скрипт автоматизации после установки новой ОС. Сейчас целюсь в Arch + GNOME (Wayland), но установка пакетов идёт через одну функцию, чтобы потом можно было добавить другие дистрибутивы.

Главная цель: потренироваться писать скрипты на bash. Возможно, позже будет версия на Python.

## Принципы

- **Идемпотентность.** Повторный запуск ничего не ломает: каждое действие сначала проверяет, не сделано ли оно уже.
- **Запуск от обычного пользователя.** `sudo` вызывается точечно внутри, весь скрипт через `sudo` не запускаем.
- **Данные отдельно от логики.** Списки пакетов и расширений хранятся в `data/*.txt`, а не в коде.
- **Модули запускаются по отдельности:** `./post_install.sh gnome`.

## Структура

```
.
├── post_install.sh     # точка входа
├── lib/common.sh       # общие функции
├── modules/NN-*.sh     # модули по порядку
└── data/               # списки и дампы настроек
```

## План

1. **`lib/common.sh`.** Функции без побочных эффектов при `source`, проверить вручную в терминале. Этап 1 (вывод и has_cmd) готов, этап 2 делаем вместе с модулями, когда понадобится.
2. **`post_install.sh`.** Скелет: подключить common, разобрать аргументы, пройти циклом по модулям. Модули на этом этапе могут быть пустыми и печатать только «привет».
3. **Пакеты (10, 20).** Сначала проверить в контейнере `docker run -it archlinux`.
4. **Docker и группы (30).** В конце вывести напоминание перелогиниться.
5. **Python и AI (40, 45).** Тут нужен `append_once` для `.bashrc`.
6. **VS Code и темы (50, 60).**
7. **GNOME (70).** Ключи искать через `dconf watch /`, сохранять через `dconf dump` в `data/`. Тестировать в виртуалке.
8. **Сеть (80).**
9. **Полировка.** `shellcheck` на всё, итоговый отчёт в конце прогона, что сделано и что требует перелогина.
